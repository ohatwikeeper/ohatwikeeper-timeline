# timeline.ohatwikeeper.com

A timeline viewer for [OhaTwi Keeper](https://ohatwikeeper.com) records, built with Next.js, Prisma and MySQL.

Live: https://timeline.ohatwikeeper.com/

[日本語](README.ja.md)

## Development

```bash
npm ci
cp .env.example .env   # fill in your values
npm run dev
```

Environment variables are listed in `.env.example`.
